## 🐛 Como Reportar Bugs

### Informações Necessárias
1. **Título**: Breve descrição do problema
2. **Ambiente**:
   - Sistema Operacional
   - Navegador
   - Dispositivo
   - Versão do App
3. **Passos para Reproduzir**:
   - Passo 1
   - Passo 2
   - Passo 3
4. **Comportamento Esperado**
5. **Comportamento Atual**
6. **Screenshots/Vídeos** (se possível)
7. **Logs** (se disponível)

### Exemplo de Report
```markdown
Título: App trava ao salvar exercício de respiração

Ambiente:
- Windows 10
- Chrome 120.0
- Desktop
- VocalCoach v0.9.5

Passos:
1. Acessar seção de exercícios
2. Selecionar "Respiração Diafragmática"
3. Completar exercício
4. Clicar em "Salvar Progresso"

Esperado: Salvar progresso e mostrar mensagem de sucesso
Atual: App trava e não responde por 10 segundos

Screenshots: [anexo]
```

## 💡 Como Sugerir Melhorias

### Estrutura da Sugestão
1. **Título**: Nome da sugestão
2. **Descrição**: Explicação detalhada
3. **Motivação**: Por que é necessário
4. **Uso**: Como seria utilizado
5. **Benefícios**: Vantagens da implementação
6. **Exemplos**: Casos de uso práticos

### Exemplo de Sugestão
```markdown
Título: Modo Offline para Exercícios Básicos

Descrição: Permitir download de exercícios básicos para prática offline

Motivação: Muitos usuários praticam em locais sem internet

Uso:
- Botão de download na página do exercício
- Indicador de exercícios disponíveis offline
- Sincronização quando online

Benefícios:
- Prática contínua sem internet
- Menor consumo de dados
- Melhor experiência em conexões instáveis

Exemplos:
- Exercícios de respiração offline
- Vocalizes básicos disponíveis localmente
- Progresso salvo e sincronizado depois
```

## ✨ Boas Práticas

### Ao Reportar
1. Verifique se o bug já foi reportado
2. Seja claro e objetivo
3. Forneça o máximo de informações
4. Use os templates fornecidos
5. Inclua evidências visuais

### Ao Sugerir
1. Verifique se já existe sugestão similar
2. Explique claramente o benefício
3. Considere diferentes casos de uso
4. Seja específico e detalhado
5. Forneça exemplos práticos

### Comunicação
1. Seja respeitoso e construtivo
2. Mantenha o foco no tema
3. Use os canais apropriados
4. Siga o código de conduta
5. Ajude outros beta testers

## ❓ FAQ

### Q: Quanto tempo leva para meu feedback ser analisado?
**R:** Bugs críticos são analisados em até 24h. Outros feedbacks em até 72h.

### Q: Como sei se meu bug foi aceito?
**R:** Você receberá uma notificação no Discord e os pontos serão creditados.

### Q: Posso sugerir várias melhorias?
**R:** Sim! Mas faça uma sugestão por vez para melhor organização.

### Q: Como acompanho meus pontos?
**R:** No seu perfil na plataforma ou usando o comando !points no Discord.

### Q: Meus pontos expiram?
**R:** Não, os pontos são acumulativos durante todo o beta.
